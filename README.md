# kevintea.github.io

**English** | [Español](#español)

Personal website and professional portfolio for Kevin Tea, published with GitHub Pages.

The site presents current work in QA automation, AI-assisted engineering, functional analysis,
portable processes, and responsible delivery. It uses semantic HTML and vanilla CSS, with no build
step or runtime dependencies.

## Structure

- `/index.html`: canonical English version.
- `/es/index.html`: maintained Spanish peer.
- `/css/site.css`: shared responsive and accessible visual system.
- `/404.html`: custom recovery page.
- `/google-clone`, `/todo-list`, `/ecclesiastical-cards`: preserved historical learning exercises;
  they are not part of the current portfolio narrative.

## Local preview

Serve the repository root with any static HTTP server. Root-relative paths intentionally mirror the
GitHub Pages deployment at `https://kevintea.github.io/`.
